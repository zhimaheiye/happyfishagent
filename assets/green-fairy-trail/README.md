## 可写进判据的结论

1. **「有没有可领」= 数绿「领取」连通域**，不能用「有没有绿色像素」—— 完成标记「✓」也是绿色大色块。
2. **「一键领取」亮/灰 = 全页可领性的总闸**，灰即零可领，可当快速出口（本次三个子页签都灰）。
    但**别点它**：作业口径要逐笔留证。
3. 🚩 **列表领一行删一行、整表上移** → 每领一次必须重新截图重量坐标。
   误点蓝「去完成」的后果是**直接退出活动页**（不是跳转），需要重进补领。
4. **到底判据**：本档用「连拍像素级一致」（`s90` 与 `s91` 一致 = 到底）。
   ⚠️ 同一天在活动大厅上这条**被推翻**（卡画有动画，PNG 字节永远在飘）→ 列表页能不能用取决于有没有动画元素，**别当通用判据**。
