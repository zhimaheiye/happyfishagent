## 能读出的通用判据（写给下一班）

1. **`[巡检-魔力召唤] ERROR：页面门禁未通过` + 队列 FAILED ⇒ 先抓一帧开图**，别去查切页延迟 / 模拟器通道 / 截图超时：本例真因是「画面停在一扇 MAA 没有分支的窗上」。
2. **`FailTaskAction` 类收口 = MAA 就地停手、不导航**（`PatrolMagicAbort` 无回主缸分支）⇒ 队列死了之后画面会**一直**保持案发帧，所以「进档抓帧」几乎总能直接拿到现场。
