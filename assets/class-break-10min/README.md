## 四、四个要点（看图时对照）

1. ⛔ **「纸币」= 开心宝**（同族别名：`钞票`、`纸币`，图标 = 绿钞堆 + 黄绑带）。底部提示里出现「纸币 xN」= 正在花钱。
2. **零氪天花板很低**：一局免费铅笔约 10 支，只够收 3 枚左右金币 → 课桌比拼第 2/3 关（5 / 8 枚）**必不通**；课间休息第 2 关也常差一颗。**是资源上限，不是操作问题。**
3. **免费次数用尽 / 笔为 0 → 一律「X → 确认」释放会话**，**别选「暂时离开」**（占住会话槽，且免费次数不随重进刷新）。
4. ★ **紫笔收币会在四邻格自动补 ✗**（正上方 / 正下方 / 左 / 右）→ 邻格若正好是另一枚金币的包围格，等于白送一格。
