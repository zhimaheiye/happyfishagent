## 从这批素材能直接读出的、可写进自动化判据的东西

1. **签到**：按钮文字 `签到` → `已签到` 是唯一可靠判据；页脚「本月已签到：**N天**」是可读的进度值（10-06 = 6 天）。
2. **连登**：7 列里**已领的列有绿勾**、可领的列有红「领取」钮、没到的列没有钮 → **判据看绿勾/红钮，不看列高亮**。
3. **连登倒计时**（主鱼缸左栏那串 `HH:MM:SS`）= **距活动结束**，不是每日重置。实测：10-06 00:12 读 `47:27:28`，而活动 10-07 23:59:59 结束 → 差 47h48m，**吻合**。
4. ⚠️ 「每日签到」卡在卡片带上，**卡片带会横向滚动** → 10-06 那帧它落在 `(1005,122)-(1274,393)`，**换个滚动位置就不在那儿了**，必须现截图 OCR「每日签到」。
