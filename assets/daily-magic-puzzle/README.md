**奖励窗**（★ 2026-09-22 起**固定选经验**，芝麻授权）

```
三卡中心 ≈ (469,336) 金币  /  (629,336) 经验  /  (788,336) 折价买(付费,永不点)

```

滑动语义：**手指方向 = 内容移动方向**，距离 = 格数 × 格距。

```bash
# 行 r 右移 k 格（4x4 棋盘 2x2 档）
adb shell input swipe $((431+138*(3-k))) $Y 847 $Y 850
# 行 r 左移 k 格
adb shell input swipe 847 $Y $((431+138*(3-k))) $Y 850
# 列 c 下移 k 格
adb shell input swipe $X $((150+138*(3-k))) $X 565 900
# 列 c 上移 k 格
adb shell input swipe $X 565 $X $((150+138*(3-k))) 900
```

## 三、两个硬注意事项

1. ⚠️ **未落子前盘面可能每 60 秒自动重随机**（游戏内 `MiniGameController::tryToRandNewGame()`）。
   → **抓帧 → 识别 → 求解 → 执行必须一气呵成**，中途别留复核空档；否则算出来的解会打空。
   （2026-09-22 在 16 块档观察到跨小时 md5 完全一致，疑似只有 4 块档会随机 —— 待验。）
2. ⚠️ **起始页那张「整图」是缩略预览，不能当模板**（尺度与明暗都和实际拼块不同，任何缩放都匹配不上）。
   但**可以当「标准答案」**：把 ▶ 用掩膜挖掉后与打乱帧做 **高通 NCC**，再用**匈牙利算法**求全局最优一对一匹配。
   - 比图形**一律用 NCC，不用 MAE**（MAE 会被亮度差淹没，信号变噪声）。
