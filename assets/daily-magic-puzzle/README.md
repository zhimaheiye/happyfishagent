### MAA 用法

| 项 | 值 |
|---|---|
| 分辨率 | 必须同为 **1280×720**（模板按 1:1 原帧裁切，**未缩放**） |
| `roi` | 建议棋盘外框 **`[346, 82, 920, 654]`** |
| 阈值 | 建议 **0.8 起**；信号强的可用 0.85 |
| 通道 | RGB，**无 alpha** |

⚠️ **左下（3 号）模板可能被 ▶ 圆钮的灰底污染** —— 未开始帧中央 2×2 正中压着播放按钮，
正好盖住左下那块。它的匹配 `diff` 天然偏高（实测可到 **47**，其余 3 块只有 1~3）。

> **判定纪律**：不要因为某块 diff 大就反复重试。只要**其余 3 块 diff < 5 且互不冲突**，
> 剩下那一格就是它。

## 四、坐标速查（1280×720 · MuMu）

```
列中心 x = 431, 570, 709, 847
行中心 y = 150, 288, 427, 565
格距     = 138 px   （滑 1 格 = 138 px）
棋盘外框 ≈ x 346~920 / y 82~654
开始钮 ▶ ≈ (640, 357)
```

滑动语义：**手指方向 = 内容移动方向**，距离 = 格数 × 138。

```bash
# 行 r 右移 k 格
adb shell input swipe $((431+138*(3-k))) $Y 847 $Y 850
# 行 r 左移 k 格
adb shell input swipe 847 $Y $((431+138*(3-k))) $Y 850
# 列 c 下移 k 格
adb shell input swipe $X $((150+138*(3-k))) $X 565 900
# 列 c 上移 k 格
adb shell input swipe $X 565 $X $((150+138*(3-k))) 900
```

## 五、两个硬注意事项

1. ⚠️ **未落子前盘面每 60 秒自动重随机**（游戏内 `MiniGameController::tryToRandNewGame()`）。
   → **抓帧 → 识别 → 求解 → 执行必须一气呵成**，中途别留复核空档；否则算出来的解会打空。
2. ⚠️ **起始页那张「整图」是缩略预览，不能当模板**（尺度与明暗都和实际拼块不同，任何缩放都匹配不上）。
   但**可以当「标准答案」**：把 ▶ 用掩膜挖掉后，跟 24 种排布逐一算 **NCC**，得分最高的就是正确排布
   （实测 0.744~0.928，次佳通常差 0.2 以上）。
   - 比图形**一律用 NCC，不用 MAE**（MAE 会被亮度差淹没，信号变噪声）。
