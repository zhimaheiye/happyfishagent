## 四、四个要点（看图时对照）

1. **`需要：A/B` = 拥有该鱼总数 / 需送出的鱼苗数**；**A 含成年鱼 → A 够 ≠ 能送**。
2. **权威判据 = 选择面板「已经选中N/M条鱼」**（默认勾「选中幼鱼」）；**N ≥ M 才送**。
3. ⛔ **按钮显示「钞票 xN」= 开心宝**；且**「送出」与「钞票 xN」是同款绿色胶囊** → 必须 OCR 读字，不能靠颜色。
4. **送出 / 删单后槽位立刻补新单**，且新单是「倒计时 + 钞票 xN」**锁定态** → **不处理**。
