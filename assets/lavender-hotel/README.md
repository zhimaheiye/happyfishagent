## 从这批素材能直接读出的、可写进自动化判据的东西

1. **入口在旅馆主页中央偏下**，按钮文本在两种状态间切换：`客房服务` / `继续游戏`；**红角标 = 当天还剩几轮免费额度**，读到 `0` 就说明跑满了。
2. **开柜页**：挂锁图标是「加锁柜」的唯一标识；免费次数直接印在黄条上（`普通柜子3/3次, 加锁柜子1/1次`），超过这个数再点就是要花钱的。
3. **走廊页**：HUD 四格读数顺序固定（金章 / 银章 / 棕章 / 笑脸总进度）；**每扇门下方就是该房的进度 `已得/容量`**；吉祥物站在哪扇门右边，那扇门上就挂着气泡 → **那扇 = 当前可服务的房**。
4. **「下个房间」的灰/黄** 是纯前端状态，判据是「当前房进度是否过半」→ 灰的时候点它无效，不用重试。
5. **气泡列出该房要的所有道具**，一样一样交；交不了的（如紫色手提包）会一直挂着 → 不影响继续交别的。
