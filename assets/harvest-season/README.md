## 从这批素材能直接读出的、可写进自动化判据的东西

1. **体力读数面板固定在右下角** `(1075,645)-(1280,700)`，是**唯一可信的余量来源** → 脚本自算的账会漂（10-06 脚本报 `剩余体力约=133`，屏幕实读 **155**，差 22，已是第 3 次）。
2. **盘面占格数**可以从 `14_棋盘裁图.png` 这张固定卡片区域直接数空格；**判「能不能发射」的阈值是 3 个空格**（游戏 toast 原文）。
3. **棋子信息面板**（右侧）会明写等级，例如 `(385,242)` 那枚贝币的面板原文是「几个贝币 **等级1**」→ **等级可以直接读，不用猜图标**。
4. 任务板**两种奖励各有一颗「收集」钮**（40⚡ / 20⚡），领完行状态会变。
