## 🚩 核心机制：气泡是**锚定**的，不是固定坐标

旧文档里「海獭摸宝」同时存在 `(296,586)` / `(352,562)` / `(293,588)` 三个互相矛盾的坐标值 ——
**三个都没错**，是当时点的宝石在配方卡上的位置不同。

→ **自动化的正确做法**：先定位**被点的那枚宝石格**，再找**气泡下沿的尖角**核对锚点，
然后按「尖角 → 按钮」的**相对偏移**算按钮位。**绝不能存死坐标。**

## 本档为什么停在「海獭摸宝」按钮前没点（第 10 项 · 未做项）

理由链三条，全部来自既有实测文档，不是推测：

1. `活动档案/宝石皇冠兑换-摸宝.md` §5.1 第 3~5 步（点「海獭摸宝」→ 寻宝页 → 点「确认寻宝」→ 好友头像页）
   **只是导航**，line 64 原文「★ 到此页 = 人工导航结束，**交给 MFA**」。
2. 第 6 步 = 在 MFA 任务列表右键「海獭摸宝」→「**单独运行**」；而 **00:00 档的 MFA 动作白名单只有「停止任务」「开始任务」两个** → 不能点。
3. 手动逐好友摸做不完：10-03 那轮 MFA 跑了 115 次 / 14 分钟。

→ 点下去只会把游戏停在好友页、无人收尾。**这是 10-06 之后连续第 2 档因同一原因做不完。**
→ 代价：46 级配方「秋翠锦鲤」的蓝紫水滴宝石仍缺 3 颗（7/10）。
