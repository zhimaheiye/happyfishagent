## 可写进判据的结论

1. **继续判据 = 红角标 > 0**；**停止判据 = 橙钮上出现「💴xN」**。后者比角标更硬，因为它直接说明已经进付费档。
2. **区域名每轮随机**：第 1 轮「**弹弹乐园**」（入水 105.55米、危险度 0.69%），第 2 轮「**海胆之家**」→ 别把区域名当状态。
3. **结算面板必须等它出现再点**，连发会空转（10-05 踩过，本档全程逐步校验后**没有再犯**）。
4. 免费次数**每日 0 点刷新**（页脚原文），所以 00:00 档做这一项是最稳的时点。
