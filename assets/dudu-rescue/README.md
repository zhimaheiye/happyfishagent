- **B 区是「只交请求一定不够」的实证**：该区走完只做出 **2/5 处「圆满」**（`圆满完成2/5处救援`），37/35 的差额是靠心形气泡补的——岩石零锤击「带走奖励」（S0049/S0061）和锦旗免费左档（S0055/S0065）。按 5 点 × 2 请求 × 2~3 算，光交请求最多 30，够不到 35。
- **耐久是跨区带入的**：B 区打完只剩 21/100，直接带进 C 区检修页起点，不是每区重置。跨区真正重置的是**补给库存与免费背包次数**（C 区准备页库存 0/0/0，[S0069_after](evidence/20261025-233933/frames/screenshots--S0069_after.webp)）。
- **QTE 单次收益不固定**：A 区 50→65（+15）、C 区 51→61（+10）。[表盘裁图](evidence/20261025-233933/frames/qte-dial-crop-20261025-2348.png)是最终命中那次的原始像素（绿弧宽 76°、奶白箭头、亮黄枢纽=旋转中心）。
