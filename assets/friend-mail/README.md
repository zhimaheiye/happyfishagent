## 从这批素材能直接读出的、可写进自动化判据的东西

1. **进面板后必须显式点页签**：面板**默认落在上次停留的页签**，不是固定回第 1 页。
2. **完成判据（两条都要满足）**：① 留言页正文 = 「**暂时没有新消息哦~请稍后再来看看吧！**」；② 回主鱼缸后**入口气泡的红点清零**。
3. ⚠️ **红点计数包含系统通知**（实测：同意掉 1 条好友申请后红点仍为 1，因为还剩 1 条「购鱼折扣券到期」系统通知）。
4. ⚠️ **别用页签上的星徽判断有没有新消息** —— 信封页签的黄色星形装饰是**常驻**的，10-06 空列表时它照样在。
5. ⚠️ **面板可能被游戏自动关闭**：隔了一轮工具操作后，拿旧截图上的坐标直接点会**落空打到主鱼缸的鱼**（09-21 踩过，鱼还弹了句台词）→ **每次点击前重新截图确认面板还在**。

## 不知道 / 没取证的（别照抄成事实）

- 点「**忽略**」到底是**删除该条**还是**转入别的分类** → 两次实测都没验证过。
- 「全部同意 / 全部忽略」的**批量上限**、以及和逐条点的差异。
- 「**奖励**」类消息的**真实长相** → 三次实测都没遇到。
- 页签 2 个人资料的**完整读数**能否当账号快照基线（10-04 记过一次数字，没做对账）。

## 本批新增的、可写进判据的结论

1. **点「同意」没有任何二次确认弹窗** —— 直接通过、整行消失。所以手滑的代价不可挽回 → 逐条处理前那一眼裁字读是唯一的闸。
2. **未读角标数 = 列表行数**，本次 3=3 一一对上；处理完角标**整个消失**（不是变 0）。
3. 本次面板**默认就落在页签 1**，没复现 10-06 那条「默认落在上次停留页签」→ 两种落点都出现过，**进面板后仍须先读页签态**。
4. **「系统通知」类消息本次未出现** —— 按契约记「本次未出现」，**不等于不存在**。
