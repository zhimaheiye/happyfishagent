# 课间十分钟

> 实测周期 **2026-09-11 ~ 09-21**（MuMu 实例 1 / `127.0.0.1:16416`），全程 **开心宝消耗 0**。
> 完整事实、全部坐标与证据截图索引见 `活动档案/课间十分钟.md`（含 `活动档案/课间十分钟/` 下 24 张图）。

## 〇、一句话

主资源是**体力**（每日赠 2 点，不随时间恢复）：体力 → 课桌比拼（下棋）→ 金币 / 口哨 / 纸飞机；金币 → 课间休息、口哨 → 操场锻炼、纸飞机 → 领奖处换鱼。
**零氪天花板很低**：一局免费铅笔只够收 3 枚左右金币 → 课桌比拼第 2 关（5 枚）/ 第 3 关（8 枚）**必然打不通**；课间休息第 2 关（蓝星 3）也大概率差一颗。**能免费推进就继续，玩不动就释放会话。**

```
① 先跑完当天的体力（课桌比拼，主入口）→ 攒金币 / 口哨
② 再消费产出：金币 → 课间休息；口哨 → 操场锻炼
③ 纸飞机够 → 领奖处兑换
```
> ⭐ **别反过来**：先跑去操场把口哨花光，会白费课桌比拼还能产出的量。主入口优先，副玩法后置。

### 3.1 棋盘网格（固定，金币位置每局重排）

| 项 | 值 |
|---|---|
| 网格 | **9 列 × 5 行** |
| 格子尺寸 | 71.44 × 74.6 px |
| 首竖线 x / 首横线 y | 342 / 254 |

```
x = 342 + (col + 0.5) × 71.44      # col 0..8
y = 254 + (row + 0.5) × 74.6       # row 0..4
```

速查：**x** = 378 / 449 / 521 / 592 / 664 / 735 / 806 / 878 / 949；**y** = 291 / 366 / 440 / 515 / 590。

### 3.2 规则与铁律

- **绿笔**：点空格画 ✗，金币被 ✗ 四面包围即自动获得。**边界即墙** → 角落金币只需 2 格、边缘 3 格。
- **紫笔**：切到紫笔后点**金币本身**直收。
- ★ **紫笔收币会在「四邻格」自动补 ✗**（2026-09-21 新发现，旧档没有）：收 c3r1 后 r0c3 / r1c2 / r1c4 / r2c3 四格同时变化。
  → 连招：「紫笔收一枚（邻格白送 ✗）→ 绿笔补最后一格围死角落金币」实测 **2 支笔换 2 枚币**。
- ★ **哪些格能下子**：除「金币格」「已下过子的格」外都能下；**红/深色只是背景涂鸦，与可下性无关**（旧档「红格不可下」是误判）。「点了没反应」几乎都是**点在格线上**了。
- ★ **紫笔耗尽后必须先点绿笔复选框切回绿笔再落子**，否则点棋盘会弹「**购买铅笔**」付费窗。
- **笔的结转**：同局内跨关结转，**跨局不结转**（每局重开文具盒）。
- **关卡**：3 关，金币 `3 : 5 : 8`；第 3 关必得鱼。奖励：第 1 关口哨 ×5、第 2 关口哨 ×12、第 3 关黄纸飞机 ×20 + 角色。
- ⚠️ **产能天花板**：3 个免费盒约 10 支笔 → 一局通常只收 3 枚左右。第 2 关 6 枚全收需 **22 支绿笔**（像素实测）→ **零氪第 2/3 关必不通，不是操作问题。**
- 🔴 **逐击操作**：B 域界面，**一击 → 一截图 → 看一眼**；禁止把多个 `input tap` 串一条 shell（会静默丢事件 + 顺手点掉中途弹窗）。
- **找作业**（收金币后概率触发）：点书堆找作业，**内容只闪现一瞬** → **纯截图流做不了，交人工**。

### 3.3 结束策略（重要）

点「继续游戏」进未完成局后，**先问一句「不花钱我还能做点什么吗？」**：
- 还能 → 继续玩（别白费体力）。
- **答不上来（笔 0 / 无免费可点）→ 点「X → 确认」释放会话**，别「暂时离开」占坑。
- 「暂时离开」**保留进度但占住会话槽**（主界面会一直是「继续游戏」，开不了新局）；免费次数**不随进馆/重进刷新** → 暂存毫无价值。

## 八、⚠️ 本活动踩过的坑（别重犯）

1. **连击盲发把「操作没生效」误判成「游戏拒收」**（2026-09-19）：连发 3 击 → 盘面毫无变化；同坐标改**单点**立即生效。真相是**连击静默丢事件** + **中途弹窗被后一击顺手点掉**。→ **B 域一律逐击留证**。
2. **「暂时离开」被当成「玩不动了」的选项**（芝麻纠正）：免费资源耗尽后不花钱什么都做不了，「保留进度」毫无价值，还会占住会话槽 → **一律「X → 确认」**。
3. **目测坐标不可靠**：本次「开始游戏」按钮用颜色扫描定到 `(625,664)`，网格标定后一次点通；目测偏差可达 100px。
4. **「存档中…」不能当生效标志**：它会不定时自己冒出来。
5. **厅里「潮汐秘宝」被误当本活动别名** → 是两张独立卡（2026-09-21 更正）。
6. **翻倍弹窗的免费按钮是延迟淡入的** → 关掉 X 后第一帧看不到「开心收下」，**多截一帧**再判断，别下「没有免费选项」的结论。
