### 2.1 🚩 核心机制：气泡是**锚定**的，不是固定坐标（★ 本文件最重要的一条）

`#100` 实测：点 `(215,600)` 那颗缺口宝石 → 弹出鱼卡片气泡，**气泡下沿的尖角正对 `(215,600)`** →
★ **气泡锚定在被点的那颗宝石格上方，不是固定坐标。**

→ 这一条**解释了旧文档里的矛盾**：「海獭摸宝」同时存在 **`(296,586)` / `(352,562)` / `(293,588)`** 三个互相冲突的坐标值 ——
**三个都没错**，是当时点的宝石在配方卡上的**位置不同**（README「🚩 核心机制」）。

→ **自动化的正确做法**：先定位**被点的那枚宝石格** → 再找**气泡下沿的尖角**核对锚点 → 然后按「**尖角 → 按钮**」的**相对偏移**算按钮位。**绝不能存死坐标。**

### 2.2 ⚠️ 三条陷阱

1. 🚩 **绝不能遮主缸右上角**：主鱼缸整帧右上 **`x900..1280 / y0..140` 是资源 HUD**（钻石 / 贝币 / 开心宝 / 等级★经验）——
   **这块绝对不能当 ID 横幅去遮**，遮掉就把「**开心宝全程 0 消费**」的证据本身毁了（README ⛔ 隐私段）。
   本页右上角是**金色装饰**，没有「你的ID为：」横幅。
2. **旧坐标别再抄**：把手 `(1193,636)` → 实测 `(1184,648)`（偏 **8px**）；宝石格**数字**在 `y≈628`、**图标**在 `y≈600`，取点别打在数字上。
3. ⚠️ **卡名有过一次自我更正**：46 级配方卡名读清是「**秋翠锦鲤**」，早前从**旧裁图**记成「**枫红竹蜻蜓**」→ **#99 明确「以本帧为准」**。教训：点之前重新截图（动作白要求）。
