# 好友消息（留言板）

> 首次实测 **2026-09-21 12:3x**，09-22、10-05、10-06 共四次取证。**全程开心宝消耗 0**。
> 完整事实见 `活动档案/好友消息.md`（本文末尾附**已脱敏**全文）。

## 〇、这个功能是干什么的

好友之间会互相发**申请 / 邀请 / 系统通知**，都堆在留言板里。每天的口径是：

| 消息类型 | 识别特征（原文） | 处理 |
|---|---|---|
| **好友申请** | 正文「**希望成为你的好友哦。**」 | ✅ **同意**（芝麻 10-05 放行） |
| 邀请看鱼宝宝 | 「我养的鱼宝宝健康又可爱，要不要来瞧瞧？！」 | 忽略 |
| 对方同意了我的好友申请（回执） | 回执类文案 | 忽略 |
| 奖励（带领取入口） | 奖品类文案 | 领（**真实长相还没遇到过**） |
| **系统通知** | 图标 = 彩色风车、署名「系统通知」 | 删除（芝麻 09-21 拍板：折扣券类他不要）；「查看」会跳消费场景 → ⛔ 不代点 |
| 其余未识别类型 | — | **先截图问芝麻，不擅自点** |

芝麻原话（2026-09-21）：「如果是邀请看鱼宝宝的，那就忽略，如果是好友申请，那就同意，如果是对方同意了我的好友申请，那就忽略……如果是奖励，就拿着，我暂时就想到这些，你需要在探索的过程中逐渐完善」
→ **这张表遇到新类型就往下补。**

## 六、★ 给「做成 MFA 可选功能」的判据（芝麻 10-05 点名要的素材）

1. **入口链**：主鱼缸 `(1195,263)` → **若落在别的页签，再点信封 `(234,50)`**；这一步**必须看图判断**，不能盲点。
2. **OCR 锚点**（比颜色可靠，符合项目纪律）：
   - 空列表 → `暂时没有新消息哦`
   - 页顶 → `未读留言最多保留15天`
   - 分节 → `邀请消息`
   - 申请特征 → `希望成为你的好友哦`
   - 批量钮 → `全部同意`
3. **颜色判据**（实测稳定，但**只当辅助**）：绿 = 同意（框宽 148~169 px、高 38~42 px），橙 = 忽略，**同行同高、橙在右**。
4. **动作**：有申请 → **优先逐条点绿钮**（可审计、单条失败不影响其余）；`全部同意` 是备选批量路。**每次动作前后都要重新截图**（面板会自动关）。
5. **完成判据**：见 §3.1 两条。
6. **参数化建议**：把「同意 / 忽略 / 删除」做成**用户可选**的开关，而不是写死 —— 芝麻原话「自动化工具做出来是**给玩家自选**的，不是只执行我这次选的那个动作」。
7. ⛔ **黑名单**：垃圾桶 `(1100,130)`、`↺ (1202,130)`、页签 4 的「添加」与邀请码相关、任何「全部忽略」。

## 七、待复验 / 待芝麻裁决

1. 点「**忽略**」到底是**删除该条**还是**转入别的分类** → 两次实测都没验证过。
2. 「全部同意 / 全部忽略」的**批量上限**与逐条差异。
3. 「**奖励**」类消息的**真实长相** → 三次实测都没遇到。
4. 页签 2 个人资料的读数能否当**账号快照基线**用于对账。
5. ⏳ 右列气泡列**第 1 个（蓝笔记本 + 星星）**是什么，仍未探。
