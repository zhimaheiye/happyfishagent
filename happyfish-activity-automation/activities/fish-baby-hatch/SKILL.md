### ⚠️ 三条血泪坑（2026-09-16）

1. **珊瑚只能点一次！** 点第二下会把刚展开的气泡**又收起来**。我连点两次 → 展开又收回，白折腾。
2. **气泡展开状态下点邻位气泡会误入别的活动**（如点 905,593 邻位 → 进**浪漫满屋**）。要认准**第 1 个气泡 (787,477)**。
3. **点不中的原因通常是被游鱼挡住，不是坐标错** → 反复多点几次（鱼游走的瞬间命中），**不要乱改坐标**。
   - 芝麻原话：「珊瑚是不会移动的，用我给的位置点就行……点一次之后截图看有没有气泡。」

> 珊瑚点开后共 **3 个气泡**（左 = 鱼宝宝 / 中 / 右），第 1 个才是鱼宝乐园。

**日记怎么读**
- 标题 = 该宝宝的**品种名**（如 三角龙鱼宝宝 / 向日葵鱼宝宝 / 枫尾礼服孔雀花鳉宝宝）。
- 表体 = **3 列 × 5 行**：3 列是 喂食(袋子) / 玩耍(手套=摸头) / 喂奶(奶瓶)；5 行是 **第1~5 次（轮）**。
- 每格 = 该次互动的**好感心数**（实心=拿到、灰=没拿到）。
- **看「第1次」行**：玩耍列 **2 心 = 选对了（+5）**；**1 心 = 不是最优（+4），要换篮球/跳绳**。

**⚠️ 三个坑**
1. **底部那排宝宝头像条不能点**（09-17 点了五六次毫无反应）→ 它只是展示，**翻页只能用左右箭头**。
2. **同品种 = 喜好相同**（09-17 观察：1/2/8 号都是「幻彩玻璃蛞蝓」→ 都是摸头 2 心）← **待复验**。
3. **坐标基准**：以上都是 adb 原图 1280×720 坐标。对话预览图缩到 1080×608，**预览上目测的坐标要 ×1.185**（09-17 就因此点偏 1.185 倍，落进表格里，误以为"按钮没反应"）。

## 二、核心规则（全部实测）

### ★ 养成机制（最关键）

1. **一套养成 = 喂食 + 玩耍 + 喂奶，三步各做一次**，**不能重复、不能遗漏**。
   - ⚠️ 我踩过：连喂两次奶 → 进度纹丝不动。**必须是三种不同的操作**。
2. **只有三步全做完，进度才一次性结算**（实测 35 → 40 = 一次完整养成 **+5**）。
3. **进度满 60 → 孵化成功**，鱼宝宝变成能在鱼缸里养的鱼。
4. **进度加成 = 玩耍那一步的好感度**：好感 **2 → +5**；好感 **1 → +4**。
   → **选对最优互动能多拿进度**，所以 4/6/7 号必须试出最优玩耍方式。

### 消耗规则（芝麻明确）

| 操作 | 位置（大类 x） | 消耗 |
|---|---|---|
| 喂食 | 左气泡 `x=500` | 玩家自购的**鱼食**（金袋一次 **-15**） |
| 玩耍 | 中气泡 `x=610` | ❤️ **爱心**（每条 100） |
| 喂奶 | 右气泡 `x=720` | **无消耗（免费）** |

### 睡眠与冷却

- 结算后**每条鱼立刻进入睡眠**（头上有 Z），并启动 **22:59:xx 的冷却倒计时**。
- **睡眠中的鱼不能被任何互动**（点它会弹「好困啊，让我再睡一会儿」）。
- → 每只鱼**每轮只能做一次完整养成**，做完等倒计时结束。
- ⚠️ 倒计时 **= 睡眠冷却**，不是"孵化剩余时间"（我一开始理解错了）。

### 好感度判定（★ 09-17 修正：以「成长日记」为准）

- **首选**：翻成长日记（见第〇·续节），**玩耍列 2 心 = 最优**。
- **备选（看不到日记时）**：做完**直接数鱼身下的红心数**：
  - **红心 = 2 → 就是它最喜欢的方式（选对了）** ✅
  - **红心 = 1 → 不是最优，下次换**（试篮球 → 再跳绳）❌
- ⚠️ 前提：只有**玩耍那步做过的鱼**，红心数才等于「玩耍好感」；混了喂食/喂奶就不可用。
- ⚠️ **台账只是缓存**（`活动档案/鱼宝乐园-好感度日志.md`）：**先翻日记，再拿台账对答案**；
  一旦**日记 ≠ 台账 → 以日记为准，当场改台账**（这通常意味着换了新宝宝）。

### 心串的含义

- 鱼宝宝旁边的**竖排 5 颗心**（上灰下红）：每成功完成一步，一颗灰变红。
- ⚠️ 灰心耗尽后当日是否还能继续做，**待复验**。

## 三、操作流程（照做）

```
主鱼缸 ─珊瑚(905,593)→气泡(787,477)─▶ 鱼宝乐园
鱼宝乐园 ─① 点「开始孵化」(640,650) ─▶ 孵化模式（8 条鱼全亮，各挂心串）
        ─★ 先点「成长日记」(63,570)，右箭头(1128,312) 逐只核对最优互动，❌(1064,50) 关掉
        ─② 选大类气泡（500/610/720, y=660）─▶ 展开 3 个子项，提示变「请选择 XX」
        ─③ 点子项（同 x 坐标）─▶ 白圈选中，提示变「请选择鱼宝宝」
        ─④ 连续点多条鱼 ─▶ 每条打绿对勾，右下爱心按条数累加（100/条）
        ─⑤ 点执行按钮 (1120,656) ─▶ 「加载中...」→ 完成后工具栏复位
```

**★★★ 批量多选（效率核心）**：选好一个互动后可**一次选中多条鱼**，一起做同一个互动。
实测一次选 **7 条**摸头，爱心 700/14722，动画同步播放。
→ 策略：**每一步把所有鱼一次选完**，共 3 轮（喂食 → 玩耍 → 喂奶）。

**「存档中...」不用等** —— 那只是游戏提示，直接接着做下一步，最后统一存档也会提交（芝麻确认）。

### 三步的默认选择

| 步骤 | 大类 | 子项 |
|---|---|---|
| 喂食 | 左 `(500,660)` | **中间那个**（金袋 50 = 「超级鱼食」） |
| 玩耍 | 中 `(610,660)` | ⭐ **先翻成长日记**；台账里★的作参考（默认摸头） |
| 喂奶 | 右 `(720,660)` | **3 号、8 号必选第 3 个「蓝莓味牛奶」**；其他随便 |

- 玩耍三种 = **摸头（手套）/ 打篮球 / 跳绳**，子项位置同大类 x。
- 喂奶三种 = 第 1 白瓶 / 第 2 黄瓶 / **第 3 蓝莓味（蓝瓶）**。
- 鱼食三种 = 左 黄袋 30 / 中 金袋 50 / 右 青花瓷袋 50。
