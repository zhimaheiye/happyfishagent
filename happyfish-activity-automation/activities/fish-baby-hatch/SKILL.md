## 二、核心规则（全部实测）

### ★ 养成机制（最关键）

1. **一套养成 = 喂食 + 玩耍 + 喂奶，三步各做一次**，**不能重复、不能遗漏**。
   - ⚠️ 我踩过：连喂两次奶 → 进度纹丝不动。**必须是三种不同的操作**。
2. **只有三步全做完，进度才一次性结算**（实测 35 → 40 = 一次完整养成 **+5**）。
3. **进度满 60 → 孵化成功**，鱼宝宝变成能在鱼缸里养的鱼。
4. **进度加成 = 三步好感度之和**：喂食恒 2 + 玩耍(1或2) + 喂奶恒 1
   → **玩耍 2 心 = +5**；**玩耍 1 心 = +4**。
   → **选对最优玩耍方式能多拿 1 点进度**，所以要把每只宝宝的玩耍项试对。

### 消耗规则（芝麻明确）

| 操作 | 位置 | 消耗 |
|---|---|---|
| 喂食 | 左大类 | 玩家自购的**鱼食**（金袋一次 **-15**/条） |
| 玩耍 | 中大类 | ❤️ **爱心**（每条 100） |
| 喂奶 | 右大类 | **无消耗（免费）** |

### 睡眠与冷却

- 结算后**每条鱼立刻进入睡眠**（头上有 Z），并启动 **22:59:xx 的冷却倒计时**。
- **睡眠中的鱼不能被任何互动**（点它会弹「好困啊，让我再睡一会儿」）。
- → 每只鱼**每轮只能做一次完整养成**，做完等倒计时结束。
- ⚠️ 倒计时 **= 睡眠冷却**，不是"孵化剩余时间"（我一开始理解错了）。

### 好感度判定（★ 09-17 修正：以「成长日记」为准）

- **首选**：翻成长日记（见第〇·续节），**玩耍列 2 心 = 最优**。
- **备选（看不到日记时）**：做完用 `scripts/count_hearts.py` **数心串**（🔴 禁止肉眼数，见「心串的含义」）：
  - 心串**自下而上**分三段：**下 2 颗 = 喂食 / 中 2 颗 = 玩耍 / 上 2 颗 = 喂奶**；
  - 判玩耍 → **看中间那 2 颗**：**2 红 = 就是它最喜欢的方式（+5）** ✅ / **1 红 = 不是最优（+4），下次换** ❌
    （摸头 → 篮球 → 唱歌 依次试）。
- ⚠️ **别数「一共几颗红」**——喂食那 2 颗恒定会给，混进来必然判错（旧版笔记就是这么写的，已废）。
- ⚠️ **结算进度是最硬的判据**：`+5` = 玩耍选对，`+4` = 没选对。
- ⚠️ **台账只是缓存**（`活动档案/鱼宝乐园-好感度日志.md`）：**先翻日记，再拿台账对答案**；
  一旦**日记 ≠ 台账 → 以日记为准，当场改台账**（这通常意味着换了新宝宝）。

### 心串的含义（★ 09-19 像素实测重写；旧版写「5 颗心」是错的）

- 鱼宝宝左上方是**竖排 6 颗心**，**自下而上**依次是
  **下 2 颗 = 喂食 → 中 2 颗 = 玩耍 → 上 2 颗 = 喂奶**；
  做过的变**亮红 `#FF494A`**，没做的保持**灰褐 `#84655F`**。
- → 一眼看进度：**顶上还剩 2 颗灰 = 还没到喂奶**；**6 颗全红 = 本轮三步齐了**。
- → 判「玩耍选对没」**只看中间那 2 颗**（见上一节）。
- ⚠️ **数心必须用 `scripts/count_hearts.py`，禁止肉眼**：
  09-19 我在缩小渲染的裁图上把 **4 心数成 3 心**，据此得出「日记页序 ≠ 孵化位编号」的**错误结论**
  （芝麻截图纠正：那正是 1 号、就是 4 颗心）。改用像素统计后：`0红6灰 → 喂食后 2红4灰 → 玩耍后 4红2灰`，
  与「喂食 +2、玩耍 +2」完全吻合。
- ⚠️ **进度条要三步做完才结算**：09-19 实测喂食＋玩耍两步做完后 `15/42` **纹丝不动**，喂完奶才 +4/+5
  → 中途看不到进度增量属正常，**别当成「这一步没生效」**。
- ⚠️ **喂奶段填 1 颗还是 2 颗，待复验**（旧记「喂奶恒 1 心」是**进度**口径，未必等于心串颗数）；
  灰心耗尽后当日能否继续做养成，同样**待复验**。

## 三、操作流程（照做）

```
主鱼缸 ─珊瑚(905,593)→气泡(787,477)─▶ 鱼宝乐园
鱼宝乐园 ─① 点「开始孵化」(640,650) ─▶ 孵化模式（8 条鱼全亮，各挂心串）
        ─★ 先点「成长日记」(63,570)，右箭头(1128,312) 逐只核对最优互动，❌(1064,50) 关掉
        ─② 点大类气泡 ─▶ 展开 3 个子项，提示变「请选择鱼粮 / 孵化方式」
        ─③ 点子项 ─▶ 白圈选中/放大，**提示变「请选择鱼宝宝」**（这是"选上了"的判据）
        ─④ 连续点多条鱼 ─▶ 每条打绿对勾，右下按条数累加消耗
        ─⑤ 点执行按钮（右下，文字 = 所选项目名）─▶ 播放动画 → 完成后工具栏复位
```

**★★★ 批量多选（效率核心）**：选好一个互动后可**一次选中多条鱼**，一起做同一个互动。
实测一次选 **8 条**，动画同步播放。
→ 策略：**每一步把所有鱼一次选完**，共 3 轮（喂食 → 玩耍 → 喂奶）。
→ 玩耍如有分歧（有的要摸头、有的要唱歌）则**分两批**：先做摸头批，再做唱歌批。

**「存档中...」不用等** —— 那只是游戏提示，直接接着做下一步，最后统一存档也会提交（芝麻确认）。
