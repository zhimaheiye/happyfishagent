## 四、★ 数字语义（最关键的一条）

> **`需要：A/B` = 拥有该鱼总数 / 需要送出的鱼苗数**

- 实证 A = 拥有数：斗鱼（紫）`0/1` 点送出 → 弹「**您没有这种鱼**」。
- 交叉验证 B = 需求数：树须泡泡（粉）`75/7`，其选择面板计数为 `已经选中4/7条鱼`。

⚠️ **A 统计该品种全部鱼（含成年鱼）→ A 够 ≠ 能送！**
实例：树须泡泡 `75/7`，A=75 看着很富，但**鱼苗只有 4 条** → 不能送。**这是最容易踩的坑。**

## 五、处理规则

| 情况 | 判据 | 动作 |
|---|---|---|
| **没有这条鱼** | A == 0（点送出弹「您没有这种鱼」） | **删单** 🗑 → 绿 ✓ |
| **有鱼但不是鱼苗 / 鱼苗不够** | 选择面板 `已经选中 N/M`，**N < M** | **也删单** 🗑 → 绿 ✓ |
| **是鱼苗且数量够** | 面板 **N ≥ M** | **送出** |

- ★ **统一判据 = 选择面板的「已经选中N/M条鱼」**（面板默认勾「选中幼鱼」，会自动选满全部鱼苗 → **N 就是该品种鱼苗总数**）。
- 只有标「**鱼苗**」的卡能被选中（选中后出现绿 ✓）；「成年鱼」卡不可选。
- 芝麻约定：**凑不齐（含"鱼苗不够"）就删单**，等游戏补新单。

### 5.1 操作流

```
进活动 → 逐槽处理（1/2/3）：
  1. 点该槽「送出」
  2. 分支：
     A. 弹「您没有这种鱼」→ 点空白关窗 → 点该槽 🗑 → 点绿 ✓（删单）
     B. 弹「选择您要送出的鱼」→ 读「已经选中N/M条鱼」
        - N < M  → 点右上 X 关掉 → 点该槽 🗑 → 点绿 ✓（删单）
        - N ≥ M  → 点底部「送出」(917,654)
                 → 弹「恭喜获得」→ 点「领取」(637,596)
                 → 高亮在 7 项里滚动一次 → 点「确定」(637,596) 关窗
  3. 回列表：**该槽位立刻补一条新单**（锁定态，见第七节）
```

> ⚠️ 每步「一击 → 一截图」，**别把多个 `input tap` 串成一条 shell**（会静默丢事件 + 顺手点掉中途弹窗）。
> ⚠️ 槽位补新单后**顺序会变** → 下次操作前必须重新截图 + 重新定位，**别背坐标**。

| 按钮 | 判断 | 依据 |
|---|---|---|
| 「**钞票 xN**」（绿色胶囊 + 钞票/纸币堆图标） | ⛔ **= 开心宝，绝对不点** | `限时融合换新啦.md` 实证「**钞票 x56 = 开心宝 56**」 |
| 「购买」（**金币图标**，选择面板底部 /「您没有这种鱼」弹窗） | ⛔ 未验证 → **默认当付费，不点** | 红线：新出现的浮空框/按钮先假定付费 |
| 删单 🗑 | ⚠️ **不可逆**，有二次确认兜底 | 芝麻已授权：没鱼/凑不齐就删 |

### ★★ 按钮颜色陷阱（写自动化必读）

**「送出」与「钞票 xN」是同一款绿色胶囊**（实测按钮区绿像素 2360~2441，两者无差别）
→ **颜色 / 像素法分不出"能不能送"，必须 OCR 读按钮文字**：

| OCR 读到 | 含义 | 动作 |
|---|---|---|
| `送出` | 已加载完成 | 可处理 |
| `xN`（无中文、旁边钞票堆图标） | 锁定态 / 付费 | ⛔ 不碰 |

「领取」按钮：奖励**无可选项**（随机奖励由游戏掷）→ **可以点**，会触发滚动高亮 → 再点「确定」关窗。

## 七、槽位被替换后的「锁定态」

**无论送出成功还是删单，该槽位都会立刻补一条全新订单**，但新单不是马上能用：

| 特征 | 表现 |
|---|---|
| 鱼位 | 被一个**白色大倒计时**盖住（`HH:MM:SS`，会走秒） |
| 按钮 | 从「送出」变成「**钞票 xN**」（付费） |
| 删除图标 | 仍在右上（还能继续删） |

★ **芝麻 09-21 明确：倒计时不用管**（推测与订单价值相关）。执行原则：
- **只处理"当前已经加载出来的订单"** —— 按钮显示「送出」的才动它。
- **没加载好的（倒计时 + 钞票 xN）一律不处理、不点、不等**。
- 每次执行都是**当场做一次**，不需要跨次跟踪倒计时。

- 附：倒计时与钞票额正相关（实测 2h→x1、5.7h→x3、19.7h→x5）。
- 观察：锁定态订单**挂机约 1 小时原样不变**（只有倒计时在减）→ 订单只在「被处理」或「倒计时归零」时才刷新。

## 九、玩法说明原文（点右上「?」读到，6 条）

1. 将鱼儿送往神秘海域，可获得神奇的魔力水晶。
2. 绿水晶 + 紫水晶可在**魔力召唤**中召唤稀有鱼 / 一级进化鱼 → `[去召唤]`（⛔ 未点）
3. **升级水晶可使进化鱼进化** → `[去进化]`（⛔ 未点）
4. **同一种鱼的鱼苗、成年鱼、皇冠鱼状态，获得的回馈是一样的。**
5. **送出皇冠鱼不会获得皇冠哦。**
6. **开启基因格子、携带基因和喂食特殊鱼粮的鱼，送出后以上物品皆会丢失哦！**

- ⚠️ **第 4 条与"只送鱼苗"规则冲突**（字面说成年鱼也能送）→ 已上报芝麻待拍板；**当前按芝麻规则执行（只送鱼苗）**，实测也支持（面板默认只勾幼鱼）。
- ★ 第 5/6 条 = 额外护栏：**不送皇冠鱼、不送带基因/喂过特殊鱼粮的鱼**（白亏）。
