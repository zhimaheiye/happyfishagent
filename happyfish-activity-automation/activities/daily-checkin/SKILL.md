### 2.1 🚩 10-08 新增：「进活动大厅」不是一个点击，是一个子过程

实测时序（`操作记录.md` #6~#8）：点左栏「精彩活动」**第一次没有进去**（画面仍是主鱼缸，鱼群正好游过图标）→ 同坐标重试 → 画面变暗 → 下一帧**不是大厅，而是「10月专属礼」充值页**。

→ 所以自动化里「进大厅」必须写成：**点入口 → 截图校验 → 若出现充值页则读标题找 X 关掉 → 再截图校验到大厅**。
→ ⛔ 该充值页三个付费钮（「充值6 ¥」/「再充6元可领取」/「储值30元预览」）**一个都不能点**；「本月已充值：¥ x0」是**读数不是按钮**。
→ ★ 它与主鱼缸「特惠礼包」是**两套**弹窗，别当成同一个。

### ⚠️ 三条坐标陷阱

1. **「每日签到」卡在卡片带上，卡片带会横向滚动** —— 换个滚动位置就不在那儿了。→ **必须现截图 OCR「每日签到」四个字**，不要抄坐标。
2. `assets/daily-checkin/03_` `04_` `05_` 三张素材**已裁掉左侧 205px**（那栏有「用户ID + 头像」）→ **在那三张图上量的 x 要 +205 才回到原图口径**。本文档给的坐标**已换算**。
   → ★ **10-08 起脱敏口径改了**：新素材用**纯色块盖住 ID 横幅**、**不裁图** → `20261008_*` 六张是原图 1280×720，**坐标无需换算**。两套口径并存，按文件名前缀分辨。
3. **签到页右上 ✕ 直接落回主鱼缸，不经活动大厅**（10-08 `20261008_06_` 实测，推翻 10-06 版本文档写的「回活动大厅」）→ 关闭后**不要**再等一帧大厅。

### 4.1 ⛔「不存在」的分支（★ 必须区分「本次未出现」和「不存在」）

- 签到页有一个「补签」按钮 —— **两次采集都没见到** → 按「未出现」处理，**不要去找**，但也**不等于游戏里没有**。
- 连登页可以**选好友绑定** —— 页面上只有「任意一人储值6元解锁」和「储值1元邀请NPC」两条口子，**都不点**。
- 签到页**没有**「今日签到给什么」的预告 —— 10-06 / 10-08 两帧都只写「额外获得 🧧x1」，走格子节点内容**不预告**（这是观察结论，不是官方规则）。
