## 〇、一句话玩法（帮助页「玩法介绍」逐字）

> 1、消耗体力参与【**沙漠种植园**】，完成播种和浇水可以获得**太阳、刺刺球、小花**。
> 2、消耗上一关获得的仙人掌章鱼参加【**中间商店**】兑换，可以获得活动道具和奖励。
> 3、消耗太阳或刺球进入【**刺刺守卫**】，通过消除小章鱼攻击怪物，可以获得**晶石**。
> 4、晶石和小花都可以兑换新鱼，累计获得**勋章**达到对应数量还可以获得新鱼。
> **注意：领奖期期间【沙漠种植园】【刺刺守卫】关闭，【探险日记】【领奖处】可以领奖。**

**资源链**：⚡体力/次数 → 种植园 → 太阳 / 刺刺球 / 小花 /（每关清空的）章鱼盆栽 → 中间商店换道具 → 守卫（太阳x20 或 太阳x15+刺球x15）→ **晶石** → 晶石+小花 → 新鱼；勋章累计 → 新鱼。

## 三、🚨 死局：**全盆枯死 = 本局报废，唯一正确处置是退出**

### 3.1 本档实测到的死亡时点（两个，都要会认）

| 时点 | 现象 | 判据 |
|---|---|---|
| **播种后即枯** | 点种子后盆里**直接是空土** + 下方「挽救」badge（第2关 4 颗里 3 颗这样） | 盆内无绿色苗 = 死；⚠️ **和"还没播种的空土盆"长得几乎一样**，必须看盆下有没有「挽救」badge 来区分 |
| **浇水后枯** | 浇完水盆里出现**耷拉的小苗** + 「挽救」badge（第1关 pot1） | 成品应是**带触手的圆胖章鱼盆栽**；不是就是死了 |

### 3.2 死局识别式（可直接写进工具）

> **本关已无种子气泡 + 已无浇水壶气泡 + 「成功种出 A/B」的 A < 过关门槛 B + 「下一关」仍灰** ⇒ **死局**。
> 此时屏幕上剩下的**每一个**可点件（挽救 / 一键成功）都要花钱或花料 → **一个都不点**。

### 3.3 本档死局实例（第2关）

- 4 盆：播种后 3 枯 1 活 → 浇那 1 活盆 → **也枯** → 4/4 全枯，计数 `0/2`，「下一关」灰。
- 处置：点右上 X `(1213,68)` → 弹「**确定现在结束游戏吗？**」双钮：橙「**确认**」`(371,585)` / 绿「**暂时离开**」`(911,585)`。
- ✅ **选「确认」结束**，理由（这条以后照抄）：
  - 「暂时离开」= 把这个**已经救不活的盘面留着占位**，下次进来还是死局，白占一次可玩状态；
  - 「确认」= 结算本局，**已经 Get 的第1关奖励不回退**（实测：结束后主页种植园角标 6→5，第1关的 小花x2 / 太阳x3 仍在资源栏）。
- ⚠️ 与酿月食香档那条「in_progress→暂时离开」**不冲突**：那条的前提是"局面还能继续玩"；**本档的前提是死局**。**先判局面，再选钮**。

### 3.4 「部分过关」的真相（差点看错）

- 第1关卡片写「成功种出 **2** 盆（0/2）」，但右侧面板写「成功种出 **0/1** 盆后过关」，且**第 1 盆成功时「下一关」就亮了**。
- → **两个计数器不是一回事**：**右侧 A/B 的 B = 过关门槛**（这里 1）；**卡片 (x/2) 的 2 = 拿满该关小花奖励所需的盆数**。
- 📌 **处置含义**：枯 1 盆 ≠ 过不了关，只是**拿不到该关的满额小花**。所以**别为"凑满 2/2"去点挽救**——本档第1关就是枯 1 盆仍正常过关并 Get 了 x2。

## 四、中间商店（每关后自动弹出）——本档一条因果最值钱

- 商人气泡原文：「**我需要：[章鱼盆栽] x3 可以给你这个：[粉鱼] x10 我还带来了下列商品**」
- 右上：「**获得的刺刺章鱼每关会清空~** 拥有：[章鱼盆栽] x2」
- 4 张商品卡（价签在钮上）：`鱼x1 ← 钞票x12`⛔ ／ `小花x1 ← 果脯x20` ／ `太阳x3 ← 绿罐x20` ／ `刺刺球x2 ← 粉肉x20`
- 底部：「**本体力累计兑换商品：0**」+ 进度条（刻度 4 / 8 / 12）→ 里程碑奖励 `太阳x5 / 刺刺球x5 / 蓝发鱼x1`

🚩 **本档最值钱的一条因果**：第1关枯了 1 盆 → 只拿到 **2 只章鱼** → 商人要 **3 只** → **这笔"章鱼x3 → 粉鱼x10"直接做不成**，而游戏递上来的补救正是「补齐兑换 **钞票x3**」。
→ **一次枯萎的代价不是"少一朵花"，而是整条商店交易被卡住，并被引导去花开心宝补差价。**
→ **以后口径**：遇到"差 N 个凑不齐"的兑换，**默认放弃这笔**，⛔ 不用开心宝补；里程碑进度条同理——**不为凑 4/8/12 而买东西**。

## 七、⚠️ 手法坑（本档自己踩的，写下来给下一次）
