# 浪漫满屋 · 约会日历小游戏

> 首次破解：2026-09-14，一轮跑通，当天 **10/10 全清**，开心宝消耗 0。
> 常驻活动，每日限次（一轮约 10 小时）。

上层通用流程（连接 / 截图 / 读界面纪律 / 红线）见主技能 `../../SKILL.md`。

## 三、核心规则（全部实测确认）

1. **放卡**：从右侧卡池把一张卡拖到**空格**上。格子只接收空位——已有内容的格子会拒收（**同色也拒**）。
2. **同色归拢**：卡片落下后，卡里的每个图标会去找**上下左右紧邻**的单色格，同色则并进去（数量相加）；找不到同色邻居的图标，留在落点格。
   - 👉 **混合卡是天然的分离器**：把「红车+怀表」放到单色红格旁边 → 红车并进去、怀表单独留在落点格 → **白赚一个干净的单色怀表格**。这是最核心的提速技巧。
3. **相邻判定**：只算上下左右 **4 邻格**，斜角不算；**同一列但中间隔着别的格也不算**。
4. **合成大日程**：某格同色累计到 **5** 个 → 该格变成「大日程」（金色大图标）。
5. **收走条件**：大日程的颜色要出现在左侧需求列里，才会被立刻收走（完成日程 +1）。需求列 3 张卡**无优先级**，任意一个被满足都会被收。
6. **需求会轮换**：橙、红、黄小花的大日程都实测被自动收走过（某一刻 4/10 → 6/10 一次跳 2 格）。所以**任何颜色的大日程都值得做**，先攒着等需求轮到它——别把「暂时没收走」当死局。
7. **每次放卡后游戏会自己再整理一轮**：相邻同色会自动合并 / 迁移，常出现「我没放卡但格子变了」的情况，属正常。
8. **卡池补充**：3 个槽位，用掉哪张空哪张，卡片**不补位**；**3 张全部用掉后一次性补满 3 张**（随机图标）。缺目标色时就把手头全当燃料丢掉换新池。

## 四、取胜策略（下一轮照做）

1. 开局先读**左侧需求列**，圈定 1~2 个目标色。
2. 给目标色选一块**空地当产区**：优先挑周围空格多的格子（**第 4 行 22–28 最空**）。
3. ⚠️ **第一大坑：不要把产区相邻格都填满**。填满了目标格就再也长不大（本次开局就踩了这个坑，绿壶铃卡在 3 个动不了）。
4. 每次放混合卡，**优先放在目标色单色格的正邻格**：目标色并进产区，杂色留在落点，**产区永远保持单色**。
5. 卡池没有目标色 → 全部当燃料丢到远处空地，清空换新。
6. 目标色到 4 时，找它**唯一的空邻居**补第 5 个 → 立刻成大日程。
7. 被堵住的目标格别硬拆：等它的邻格大日程被需求收走后，空位自然出现（本次 3 号格、8 号格都是这么解冻的）。
