## 七、机器能力备忘（写自动化时直接抄）

- **判定任务是否在跑，只看日志**：`[src=UI][op=StartTask]` / `准备执行任务队列` = 起了；`已放弃本次任务` = 停了。**MaaMCP 的 `click` 返回 `true` 不能证明点中了。**
- **MFA GUI 的右键菜单**：MaaMCP 的 Win32 右键（PostMessage）**不出菜单**；要用真实鼠标事件（本机用 computer-use 的 `click` + `mouse_button:"right"`）。
- **「单独运行」在队列跑着时是灰的**（a11y 树里 `menu item (disabled) 单独运行 ID:TaskMenuRunSingle`）→ 想单独跑一个任务，**必须先把队列停掉**（`停止任务` → `已放弃本次任务`），跑完再点「开始任务」恢复。芝麻 10-06 的实测序列就是这样：09:15:00 停止 → 09:15:13 鱼宝乐园单独运行 → 09:16:34 放弃 → **09:17:06 手动 `[src=UI][op=StartTask]` 恢复巡检**。
- **单独运行不会自动把巡检接回来**，恢复要人工点一下。
- **海獭摸宝的配额**去看 GUI：任务说明面板写 `今日完整运行：N / 3 次`、`游戏日：<日期>`、`上次完整运行：<时间>`，并注明「仅"完整正常结束"的一次任务会 +1；Safety Limit、手动停止、异常中断不计数」。
