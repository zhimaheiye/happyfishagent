## 一、结论（一句话）

末位好友之后翻到**推荐玩家页**时，判定要求"确认寻宝体力耗尽"才肯正常收摊；
本次它只拿到 **1 次** `ui=EXHAUSTED` 就放弃 → 走 `门禁未通过，安全失败，未继续点击`。
而**人工在同一现场连按 3 下「返回」，游戏始终没有弹「您还有未使用的体力」**
→ 按 `activities/sea-otter/SKILL.md` §五 的唯一硬判据，"不弹"= **体力确实归零**。
**两边不可能同时成立**：MFA 说"没确认到耗尽"，游戏说"没剩"。这与缺陷 #13（提前收工却记成功）是**同一族的另一面**。
